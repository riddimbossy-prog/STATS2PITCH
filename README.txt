Stats2Pitch old-engine cache fix

Replace only this file in your local GitHub Desktop repository:
  server/refresh.js

What this fixes:
- Old settled picks from earlier engines are no longer carried into boards generated by simple-odds-consensus-v1.
- Previous snapshots are only reused when previous.meta.engineVersion matches the current ENGINE_VERSION.
- After replacing the file, commit and push in GitHub Desktop, then run/allow the board refresh workflow.

Do not replace your whole project with this ZIP. Copy server/refresh.js into the matching server folder of your existing STATS2PITCH repo.
